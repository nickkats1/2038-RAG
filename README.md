This repository consists of Retrieval Augmented Generation on my novel (now on spotify) "2038". I do RAG on my novel, not to promote it, but to really FEEL the importance of RAG. I know that novel inside and out, I will feed it to a large langauge model to overserve the halluciantations.

## Why this repo

Lots of people learn RAG incorrectly and/or over-complicate it. The best way to understand the reason for RAG, is to do the following:

1. Use a document which you know very well and is not public and put it into a chat model.
2. When the document is in the chat model, start asking questions you know the answer to from the document.
3. See who much is made up.

This is why RAG is so crucial.


## Forms of RAG used in this repository

- Dense (faiss)
- Sparse (BM25)
- Hybrid (Dense + BM25)
- Graph Rag
- Agentic RAG
